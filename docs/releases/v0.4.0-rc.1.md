# v0.4.0-rc.1 · 主对话通知与 Windows 审批卡片更新

这是适配 **DSH 0.1.7-rc.2** 的预发布版本。本次重点是：只保留主对话通知、增加本轮完成/异常提醒，并修复长审批原因导致摘要提示在通知中心不可见的问题。

## 新增与变更

- 主对话完成一轮实际执行后显示“本轮回复已完成”；出错、受阻、达到输出上限分别提醒。
- 任务通知默认静音，可配置显示任务标题或会话短 ID。
- 全部子代理通知关闭，旧 `notifyOnSubagentStart` / `notifyOnSubagentEnd` 即使为 true 也无效。子代理审批交回宿主其他应答者处理，不自动放行。
- 审批卡片明确“批准仅本次”、拒绝语义与真实超时动作；任务/操作/原因独立摘要。
- 截断提示放到原生 attribution 区域。Windows 11、100% 缩放实测：长原因折行后，横幅与通知中心展开态仍完整显示“（摘要，详情见 DSH）”。
- 强化结构化参数门：非法输入映射渠道不可用，生产路径在注册/状态写入/投递前退出；不谎报成用户拒绝。
- 保留并发队列、撤回与卸载清理、SQLite 单实例锁及审计故障不放行行为。

## 下载与安装

下载附件 **`dsh-approval-center-0.4.0-rc.1.tgz`** 和 **`SHA256SUMS.txt`**。Source code 压缩包不是可直接安装的构建包。

```powershell
Get-FileHash -LiteralPath 'C:\Downloads\dsh-approval-center-0.4.0-rc.1.tgz' -Algorithm SHA256
dsh plugin --profile web add 'C:\Downloads\dsh-approval-center-0.4.0-rc.1.tgz'
```

或直接安装固定 URL：

```powershell
dsh plugin --profile web add https://github.com/xmwpoi/dsh-approval-center/releases/download/v0.4.0-rc.1/dsh-approval-center-0.4.0-rc.1.tgz
```

安装前需要 Windows、Node.js ≥24、PATH 上的 pnpm 与精确 DSH 0.1.7-rc.2。安装后通常需重启宿主；确认 profile 中只有一个 approval-center 实例，勿额外添加 insert。

## 配置与升级提醒

默认开启主对话完成/异常提醒，任务通知静音；审批结果回执默认关闭。`taskNotificationSound` 不控制审批声音，当前审批没有独立静音开关。

升级前停止旧宿主，备份 profile 与审计数据库（存在 WAL/SHM 时一并备份）。同一 dataDir 不要新旧混跑；回滚前再次备份。旧子代理通知历史不会自动清空。

完整配置、安装排错与备份/回滚说明见 [README](https://github.com/xmwpoi/dsh-approval-center/blob/v0.4.0-rc.1/README.md)。

## 已验证与未测范围

R11 运行代码通过 282 项单测与 120 项目标版集成。新脚本参数门 9/9、生产非法输入 4/4。Windows 11 26100、100% 缩放完成 17 例横幅及原 M7 通知中心展开态复验，并核验批准、拒绝、真实超时、任务通道冒烟与注册恢复。

“本轮完成”不等于整体任务目标完成。系统通知设置、勿扰、权限与限流可能影响显示。

未测范围：125%/150% 缩放、旧 Windows attribution 兼容、真实 child 委派、生产模型体验、20 路大批次实机、生产升级后完整回装演练。0.1.5-rc.1 仅有观察性回归，不承诺双版本支持。

附件以本 Release 的 `SHA256SUMS.txt` 为准。更新发布文档后的包与实机包 SHA 不同，运行文件须逐字节一致并经发布流程核验；不要使用历史候选 SHA 校验最终附件。
